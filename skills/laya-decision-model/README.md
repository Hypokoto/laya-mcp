# Laya Decision Model

Use the Laya MCP server to make fast, calibrated classification, scoring, routing, and probability-based decisions from structured data.

## Usage
Trigger this skill by using phrases like:
- "Use Laya to classify this"
- "Run this through Laya"
- "Use the Laya MCP to decide"
- "Score/classify these items with Laya"
- "Route these based on Laya's decision model"

This skill helps you integrate Laya into your workflows as a fast decision and routing layer rather than relying on text generation.
